# Effect-only classifier — ADVANCED
Codes only. Never say names, form, color, route, or dose in questions asked to the person.
Lock a code only after **≥5 of 6** confirmers hit (6/6 = sure). If two codes both ≥5, run the duel set.
Emergency first: slow breath, unresponsive, chest pain → stop the game.

## Hidden map (operator)
- a short wired confidence, fast fade, talk, little world-change
- b warm loose social, clumsy, later fog
- c energy + love/open, music/touch, jaw, room still real
- d long mechanical drive, no sleep, later grind
- e warm social then cliff / blank memory
- f soft time, giggle/hush, appetite, mild warp
- g living/nature visuals, body wave, meaning, stomach wave
- h long geometry/loops, time broken, ego thin
- i-nod warm nod / itch / pain mute  |  i-rush tiny violent spike then dead
- j lights cut, almost no story, alertness collapse
- k body unplugged, rooms stretch, float/hole
- l wired + jelly/unplug together

## How to run
1. Ask **Q1** then follow the route until a *candidate*.
2. Do not announce the candidate. Run that code’s **6 confirmers**.
3. Score Yes=1, No=0, Unsure=skip (need 6 answered; if skip, pull a duel item).
4. Lock if ≥5. If 3–4, ask one more route from another flow of the same code. If ≤2, abandon and restart from Q1 with the leftover branch.
