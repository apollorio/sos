# 009 · Laboratório beta: small-group testing and clinical approval

**Date:** 2026-09-25 · **Branch:** `claude/connect-i913l0` · **Numbering:** 004–008 are reserved for off-computer phases
(hospitals, government, partnerships), so this phase is 009.

## Request (owner)

> "Prepare a beta lab version based on all information we have, to test and simulate with a small group and to share
> with doctors for approval. Gateway entrance at the root of apollorio/sos as index.html, and the entire app in /app
> with index.html as the entrance door."

| Path | Before | After |

## Decisions

1. **The engine is the entrance door at `/app/`** as requested. The legacy page stays reachable at `/app/legacy.html` for
   comparison and as a fallback; it keeps its e2e guard.
2. **Beta is stamped, not remembered.** `scripts/build.ts` stamps `<html data-channel="beta">` whenever
   `registry:lint --release` fails (17 errors today). The shell shows "Versão beta de teste. Os textos clínicos ainda estão
   em revisão." with a link to the lab. The notice disappears only when the gate is green (tested both ways by
   `tests/build/stamp.test.ts`).
3. **CSP travels with the app.** A strict policy (`default-src 'self'`, no inline script or style) is in a `<meta>` tag of
   `app/index.html`, so it holds on hosts that ignore `_headers`. The e2e proves no violation from boot to P0, and a control
   proves an injected inline script is refused. The gateway and legacy page get no CSP: they still load `core.js`/GSAP/fonts,
   which is the open owner decision from audit 003.
4. **Nothing in the lab is hand-written about the engine.** Missions replay golden scenarios through the real engine and
   quote the real labels and cards; the review sheet reads the registry and the locale. One scenario was added for the
   "Tô bem, encerrar → Apagar agora" story (`calm-end-and-wipe`, with a new `status` expectation).
5. **Feedback is a file the person sends.** No backend, no analytics. `npm run review:summary` reads a clinician's export and
   prints Markdown; it never edits the registry. Approval stays a signed human step (CLAUDE.md rule 8).
6. **Lab-only reset.** "Apagar os dados do app neste navegador" deletes the app's two IndexedDB databases so each mission can
   start from zero. The app itself is unchanged; it keeps "Apagar agora".

## Findings

| # | Finding | Status |
|---|---|---|
| F1 | **The release lint does not cover all clinically relevant copy.** Only 16 of the 35 cards are flagged `clinical` in `pt-BR.json`. The three grounding exercises (whose contraindications were audit 003's first blocker) and seven triage questions (e.g. `CARD_Q_CLARITY`, which sets `responsiveness=impaired`, and `CARD_Q_HOW_NOW`, asked when a self-harm or danger phrase is negated and at check-ins) can reach release without a clinician's signature. | The review sheet requires them anyway (59 required items, 6 optional). **Owner decision:** flag them `clinical` so the lint matches. |
| F2 | The gateway's visible links were absolute to production. On a preview host, "Preciso de ajuda" would have left the beta for the live site. | Fixed: relative links; e2e clicks through from `/` to `/app/`. |
| F3 | The gateway still loads `core.js`, GSAP and Google Fonts, plus two `../../_lib/…` scripts that do not exist outside the author's machine (404 on any host). | Open, owner (with audit 003's `core.js` decision). |
| F4 | **Rule 8 exposure.** Merging this branch into the branch that serves sos.apollo.rio.br makes the draft engine the live `/app/`. The beta notice would be visible, but the rule forbids shipping with the release gate red. | Documented in `docs/BETA-LAB.md` and CLAUDE.md: share via a preview URL; merge only after sign-off. Owner decision. |
| F5 | Missions that tap "Ligar 192/188" or "Abrir WhatsApp" open the real dialer or a real message. | Every such step carries a red "cancel, do not complete" warning (tested); every lab page has the safety box; the simulator is offered as the no-dialer alternative. |
| F6 | `docs/BLUEPRINT.md` said "14 golden stories"; there are 18. | Fixed (and mirror). |
